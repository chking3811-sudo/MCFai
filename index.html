VentureLink.Private inbox & saved work

One-time setup needed

This page needs a Supabase project to securely create accounts and sync inbox messages and saved work across devices. It is not connected yet.

  1. Create a Supabase project.
  2. Run the SQL in supabase-setup.sql in the project's SQL Editor.
  3. Set your project URL and publishable (anon) key in the configuration at the top of this page's script.
  4. For password-only signup, turn off email confirmations under Authentication → Sign In / Providers → Email. Use strong passwords; don't reuse an important password.

Passwords are handled by Supabase Auth and are never saved by this page. The public key is safe to put in a browser only when the database row-level security policies from the SQL file are enabled. This app does not send email notifications; recipients see messages when they sign in.
